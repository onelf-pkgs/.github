## onelf-pkgs

Shared builds for [onelf](https://github.com/QaidVoid/onelf) packages,
built from source, versioned, and released with build provenance.

| Package | Provides |
|---------|----------|
| [mesa](https://github.com/onelf-pkgs/mesa) | GL and Vulkan drivers without a shared libLLVM, for bundles to carry |

Every package is maintained from the
[control repository](https://github.com/onelf-pkgs/.github): it follows
upstream releases, builds each one on every architecture, and releases
it once the build and its tests pass.
